# AI Video

面向影视、广告片、宣传片和短剧制作的 AI 视频生成工作流项目。

## 当前路线

- ComfyUI 作为制作总控台。
- LTX-2.3 FP8 作为新的开源视频生产主线。
- HunyuanVideo-1.5、SkyReels-V2、Wan2.2 等模型按镜头需求补充或作为对照基线。
- GPT Image / TTS / 音乐 / LLM / 视觉设计等非视频 API 用于分镜、关键帧、参考图、配音、音乐、字幕和包装辅助。
- FFmpeg / 剪辑工具用于后期合成、转码、字幕和交付。

## 当前状态

- 已完成远程 GPU 服务器基础部署。
- 已在 AutoDL 数据盘下载 Wan2.2 TI2V 5B 的 ComfyUI 最小组合。
- 已用 Wan2.2 TI2V 5B 跑通多条基线视频，确认 ComfyUI 远程生成链路可用。
- 下一步切换到 vGPU-48GB-350W / 48GB、90GB 内存服务器，部署 LTX-2.3 FP8 生产工作流。

## 仓库原则

本仓库只保存可版本管理的内容：

- 项目计划和部署记录。
- ComfyUI 工作流 JSON。
- 安装、启动、检查和批处理脚本。
- 提示词模板、镜头表、模型清单、制作规范。

不提交以下内容：

- 模型权重。
- 生成视频、图片、音频等大文件。
- 服务器密码、API key、token、SSH key。
- ComfyUI 运行缓存和临时文件。

详细进度见 [计划.md](计划.md)。
