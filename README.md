# AI Video

面向影视、广告片、宣传片和短剧制作的 AI 视频生成工作流项目。

## 当前路线

- ComfyUI 作为制作总控台。
- Wan2.2 TI2V 5B 作为第一阶段主视频模型。
- LTX、HunyuanVideo、SkyReels 等模型按镜头需求逐步补充。
- FFmpeg / 剪辑工具用于后期合成、转码、字幕和交付。

## 当前状态

- 已完成远程 GPU 服务器基础部署。
- 已在 AutoDL 数据盘下载 Wan2.2 TI2V 5B 的 ComfyUI 最小组合。
- 下一步是导入或构建 Wan2.2 测试工作流，并生成第一条 5-10 秒测试视频。

## 仓库原则

本仓库只保存可版本管理的内容：

- 项目计划和部署记录。
- ComfyUI 工作流 JSON。
- 安装、启动、检查和批处理脚本。
- 提示词模板、镜头表、模型清单、制作规范。

不提交以下内容：

- 模型权重。
- 生成视频、图片、音频等大文件。
- 服务器密码、API key、token、SSH key。
- ComfyUI 运行缓存和临时文件。

详细进度见 [计划.md](计划.md)。
